Your Claude Code quotas, always in view

Two mini bars in the Xfce panel: the 5-hour window on top, the week below. No more clearing your desktop to check where you stand.

The bar in the panel above is the real rendering, at actual size. Move the controls to see how it reacts.

Try the bar

Data state

Reading the bar

What you seeWhat it means
5-hour bar: under 60 %, under 85 %, above.
7-day bar: you are using your quota at the pace of the week, with a 5-point margin.
7-day bar: you are using your quota faster than the week goes by.
The dark mark shows how much of the week has already passed.
Data older than 15 minutes: the numbers are no longer current.
–A reset has passed and new numbers are on their way; or data is unavailable.

Hover over the bar for details: plan, reset times, time left, weekly pace and the time of the last update.

The bar itself is in French, like the Conky widget it builds on: it reads 5 h and 7 j (7 jours), and its tooltip is in French. The tooltip on this page is translated.

Install

  1. Install claude-monitor, the service behind the Conky Claude Code widget, from its French version: it computes the weekly pace the bar needs. It checks your account every 5 minutes and writes the numbers to ~/.local/share/claude-monitor/current.json, which the bar reads.

    git clone https://github.com/scriptor-pro/ConkyClaudeCode.git
cd ConkyClaudeCode
./install.sh

  2. Install the genmon plugin and Cairo for Python:

    sudo apt install xfce4-genmon-plugin python3-cairo

  3. Get this project and install the claude-barre-quotas command:

    git clone https://github.com/scriptor-pro/plugin-claude-taskbar.git
cd plugin-claude-taskbar
./install.sh

  4. Right-click the panel, Panel, Add New Items: add a Generic Monitor and place it where you like. In its properties, enter the command with its full path, for example /home/you/.local/bin/claude-barre-quotas, untick Label and set the period to 60 seconds.

The bars use Luciole, a typeface designed for people with low vision. Install it to get the same rendering.
