Vos quotas Claude Code, toujours en vue

Deux mini-barres dans le tableau de bord Xfce : la fenêtre de 5 heures en haut, la semaine en bas. Plus besoin de dégager le bureau pour savoir où vous en êtes.

La barre ci-dessus, dans le tableau de bord, est le vrai rendu à taille réelle. Faites varier les réglages pour voir comment elle réagit.

Au survol, une infobulle donne le détail : forfait, heures de réinitialisation, temps restant, rythme de la semaine et heure de la dernière mise à jour.

Installer

  1. Installez claude-monitor, le service du widget Conky Claude Code, depuis sa version française : elle calcule le rythme de la semaine, dont la barre a besoin. Il interroge votre compte toutes les 5 minutes et écrit les chiffres dans ~/.local/share/claude-monitor/current.json, que la barre lit.

    git clone https://github.com/scriptor-pro/ConkyClaudeCode.git
cd ConkyClaudeCode
./install.sh

  2. Installez le greffon genmon et Cairo pour Python :

    sudo apt install xfce4-genmon-plugin python3-cairo

  3. Récupérez ce projet et installez la commande claude-barre-quotas :

    git clone https://github.com/scriptor-pro/plugin-claude-taskbar.git
cd plugin-claude-taskbar
./install.sh

  4. Clic droit sur le tableau de bord, Tableau de bord, Ajouter de nouveaux éléments : ajoutez un Moniteur générique et placez-le où vous voulez. Dans ses propriétés, indiquez la commande avec son chemin complet, par exemple /home/vous/.local/bin/claude-barre-quotas, décochez Étiquette et réglez la période sur 60 secondes.

La police des barres est Luciole, conçue pour les personnes malvoyantes. Installez-la pour obtenir le même rendu.
